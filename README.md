# NEON HOOPS 7 — готово к размещению в интернете

Это рабочая онлайн-игра 1v1 и Node.js WebSocket-сервер. В режиме против бота можно играть одному.

## Размещение через Render (публичная ссылка)

1. Создай GitHub-репозиторий и загрузи **файлы из этой папки в корень репозитория** (не сам ZIP-файл). На GitHub можно нажать `Add file → Upload files`.
2. В Render создай **Web Service** из этого репозитория (или используй Blueprint из `render.yaml`).
3. Если создаёшь Web Service вручную: Runtime **Node**, Build Command **npm install**, Start Command **npm start**, Health Check Path **/health**, Instances **1**. Выбирай Free только если он доступен и подходит; иногда бесплатный сервер засыпает при простое.
4. Когда Render покажет `Live`, открой выданный адрес `https://...onrender.com/` на обоих компьютерах.
5. Первый игрок: «ОНЛАЙН 1 НА 1» → «СОЗДАТЬ КОМНАТУ». Второй открывает **тот же адрес** и вводит код комнаты.

**Пока приложение не опубликовано, публичной ссылки не существует.** Для публикации понадобится аккаунт хостинга. Не указывай пароли в ZIP или чате.

## Локальная проверка (если установлен Node.js)

```bash
npm start
```

Открой `http://localhost:3000/`, проверка сервера: `http://localhost:3000/health`.

Используются только встроенные модули Node.js, установка дополнительных npm-пакетов не требуется. Вся физика считается на компьютере создателя комнаты, поэтому при высокой задержке интернета движения второго игрока могут ощущаться менее отзывчивыми. Комнаты живут в памяти и исчезают после перезапуска сервера.
